How this site is built

A static portfolio with one procedural scene, a small hand-written design system and no runtime framework.

The build

Vite handles the build and serves the development version. The pages are plain HTML with one shared stylesheet; the interactive parts are small ES modules. The home page, four case studies, three articles, the writing index, the colophon, the CV and the 404 are separate build entries, which keeps each page statically renderable and directly linkable.

There is no UI framework. The page-level behaviour — the mobile menu, the day/night dial, the year stamp — is a few hundred lines in total, and the sections below the hero render immediately with no scroll-triggered animation.

By the numbers

  • Initial JavaScript for the page: about 52 kB, or 18 kB gzipped (including the three-language dictionary).
  • The scene chunk: 626 kB, 158 kB gzipped, requested after the page is usable.
  • One stylesheet: 40 kB, 8 kB gzipped.
  • Seven font files: 136 kB in total, served from this origin.
  • Third-party font, script or style requests: none.

The hero

Three.js renders a single scene: a workstation, water, sky, particles and a day-to-night atmosphere. A custom screen-space pass quantises the frame with an 8×8 Bayer pattern; the write-up covers the shader. The scene module is loaded on idle instead of in the first payload, which keeps the initial JavaScript to the site's own UI code. The render loop pauses when the hero is offscreen or the tab is hidden, and Save-Data visitors get the static background.

Type

Cabinet Grotesk, Satoshi and Clash Display are free Fontshare faces; IBM Plex Mono is under the SIL Open Font License. All of them are self-hosted — no requests to a font CDN at runtime. That removes a third party from the critical path, avoids a cache dependency that had already broken once, and means the site works the same behind a strict network.

Images

Project screenshots are served as WebP with a JPEG fallback and a two-width srcset, so a phone does not download a 1440-pixel image. They are lazy loaded below the hero, and every one carries a description of what it actually shows.

Accessibility and motion

The page has a skip link, a visible focus ring, a keyboard-operable dial, and a full forced-colors treatment. The time-of-day dial is a real slider with arrow, page, home and end keys. With prefers-reduced-motion, the scene's clock stops and the interface drops its transitions; when the tab is hidden, rendering stops entirely.

Analytics and privacy

No cookies, no fingerprinting, no consent banner. The site is wired for cookieless GoatCounter events (project and case-study opens, phase changes) and loads no analytics script until an endpoint is configured.

Hosting

GitHub Pages serves the site, and a GitHub Actions workflow builds it on every push to main. Only source is committed; the build output is never pushed to the branch. The canonical URL is thijnperd.github.io.
