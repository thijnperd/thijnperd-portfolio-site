# thijnperd.github.io

Personal portfolio of Thijn Köhne (`thijnperd`), built with Three.js, custom GLSL dithering shaders, plain CSS, and Vite.

**Live:** https://thijnperd.github.io/

## Development

```bash
npm install
npm run dev
npm run build
```

Pushing to `main` deploys the built `dist/` bundle to GitHub Pages via `.github/workflows/deploy.yml`.
